# Разработка рекомендательной системы фильмов с диалоговым LLM-агентом

Проект по предмету «Проектная деятельность» (5 семестр).

Идея: классические рекомендатели (CF/SVD) дают честные метрики, нейросетевой подход добавляет эмбеддинги, а диалоговый LLM-агент превращает top-N в понятный человеку ответ с объяснением — «почему вам это подойдёт».

## Пайплайн (ступени)

1. **CF (collaborative filtering)** — бейзлайн по рейтингам MovieLens
2. **SVD (матричная факторизация)** — та же задача матрицы оценок через латентные факторы
3. **Нейросетевой рекомендатель** — эмбеддинги пользователей/предметов (NNCF-стиль)
4. **Гибрид** — склейка классики и эмбеддингов
5. **Диалоговый LLM-агент** — объясняет рекомендации «почему этот фильм» в диалоге, уточняет вкусы пользователя (вопросы, пересбор профиля)

Ступени 3–4 — второй этап: базу (CF/SVD) делаем первой, она даёт метрику для сравнения.

## Данные

MovieLens (GroupLens, университет Миннесоты) — готовый датасет оценок фильмов: `ml-latest-small` для разработки, `ml-25m` для финальных рунов. Датасеты в git не хранятся — качаются скриптом:

```bash
python data/download_movielens.py
```text

## Структура

```text
data/       — скрипты получения данных (сами данные — не в git)
notebooks/  — исследование датасета, метрики этапов
src/rec/    — рекомендательное ядро: CF → SVD → NN → гибрид
src/agent/  — диалоговый LLM-агент (объяснение рекомендаций)
docs/       — постановка, этапы, отчётные материалы
```text

## Метрики

RMSE/MAE — на предсказание оценки, Precision@k / Recall@k — на подбор top-N; сравнение ступеней между собой на одном сплите.

## Стек

Python 3.11+, pandas, numpy, scikit-learn; LLM-агент — локально (Ollama) или через API. Права и правила работы — в `COLLAB.md`.
