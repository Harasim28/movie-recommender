# COLLAB.md — правила совместной работы

- Источник истины — этот репозиторий (main); зеркала — через git bundle/почту.
- Один пакет доработок = один коммит: заголовок «этапN: суть», буллеты «что и почему».
- Тесты/скрипты перед пушем: пайплайн должен воспроизводиться с чистой папкой (`data/download_movielens.py`).
- В git не кладём датасеты (>10 МБ) и ключи API — только скрипты и README.
- Взаимодействие с нейросетевыми ассистентами фиксируем открыто: промпты/правила — в `docs/ai-worklog.md`.
